# 🧠 AI Customer Service & Ordering Web Application

This is a full-stack AI-powered web application that provides customer service and order handling through voice interaction. The app integrates **Vapi AI** to act as a conversational agent, with a **React.js** frontend and a **Python Flask** backend to process API calls. It is deployed on a live server for real-time use.
